# React Projects

A home for my React practice projects and job-portal exercises.

## Projects in this repository

| Project | Description | Run locally |
| --- | --- | --- |
| [Smart Expense Manager](./smart-expense-manager/) | Track expenses and review spending in a React dashboard. | `cd smart-expense-manager` |
| [CareerConnect](./mern-internship-react/CareerConnect/) | A job portal interface built with reusable React components. | `cd mern-internship-react/CareerConnect` |
| [CareerConnect mini project](./mern-internship-react/CareerConnect1/) | A searchable job board demonstrating component composition and props. | `cd mern-internship-react/CareerConnect1` |

From a project directory, install dependencies and start the development server:

```sh
npm ci
npm run dev
```

Run `npm run lint` and `npm run build` in any of the Vite projects to check it locally. GitHub Actions runs both checks for all three projects on pushes and pull requests to `main`.
