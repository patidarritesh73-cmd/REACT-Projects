# React-projects

This repository contains the `mern-internship-react` exercises and CareerConnect projects.

## Projects

- `CareerConnect/` — CareerConnect job portal exercise.
- `CareerConnect1/` — reusable CareerConnect job portal mini project.

Each project is a Vite React app. To run one, change into its directory, install dependencies, then start the development server:

```sh
npm install
npm run dev
```
