# REACT-Projects

This repository contains React practice projects, including the Smart Expense Manager and CareerConnect job portal exercises.

## Projects

- `smart-expense-manager/` — Smart Expense Manager.
- `mern-internship-react/CareerConnect/` — CareerConnect job portal exercise.
- `mern-internship-react/CareerConnect1/` — reusable CareerConnect job portal mini project.

The CareerConnect projects are Vite React apps. To run one, change into its directory, install dependencies, then start the development server:

```sh
npm install
npm run dev
```
