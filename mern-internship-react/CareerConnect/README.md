# CareerConnect

A React job-portal interface exercise featuring job listings, search, and reusable UI components.

## Requirements

- Node.js 22.12+ (or 20.19+)
- npm

## Run locally

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The application entry point is `src/App.jsx`; reusable interface components are in `src/components/`.
