# CareerConnect Job Portal

A responsive React job board demonstrating reusable components, props, and data-driven rendering. It includes a searchable set of ten sample jobs, company and skill details, and reusable apply buttons.

## Requirements

- Node.js 22.12+ (or 20.19+)
- npm

## Run locally

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

Job and statistics data live in `src/data/`; the interface is composed from components in `src/components/`.
