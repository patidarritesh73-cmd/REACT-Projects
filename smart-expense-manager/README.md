# Smart Expense Manager

A React and Vite expense-tracking dashboard for recording expenses and reviewing spending.

## Requirements

- Node.js 22.12+ (or 20.19+)
- npm

## Run locally

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The app source is in `src/`, with reusable dashboard and expense components in `src/components/`.
